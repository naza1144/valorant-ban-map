# เชื่อมเว็บ Ban Map กับ Google Sheet

เว็บเขียน Google Sheet ตรงๆ ไม่ได้ จึงใช้ Apps Script ผูกกับชีตเป็นตัวกลาง (ทำครั้งเดียว)

1. เปิดชีต UVC รวมคะแนน แล้วไปที่ Extensions > Apps Script
2. ลบโค้ดเดิม วางเนื้อหาจาก `Code.gs` ลงไป
3. แก้ `const TOKEN = 'change-me'` เป็นรหัสลับของคุณเอง
4. Deploy > New deployment > ประเภท Web app
   - Execute as: Me
   - Who has access: Anyone
5. อนุญาตสิทธิ์เมื่อ Google ถาม แล้วคัดลอก Web app URL (ลงท้ายด้วย `/exec`)
6. ในหน้าเว็บ ใส่ URL กับรหัสลับ กด "โหลดรายการ" เลือกวันที่และแมตช์ แล้วเริ่ม Ban/Pick

ทุกครั้งที่ ban/pick/เลือกฝั่ง/ย้อนกลับ เว็บจะอัปเดตแถวของแมตช์นั้นในชีตทันที:

| ใน Sheet | ค่าที่เขียน |
|---|---|
| แถวชื่อแมพ (Abyss, Bind ...) | แดง = แบน, เขียว = เลือก/แมพสุดท้าย, ไม่มีสี = ยังไม่ถูกเลือก |
| แถว map1/map2/map3 | ลำดับที่เล่น |
| แถวถัดไป | ทีมที่เลือกแมพนั้น |
| แถวถัดไป | ฝั่งของทีมที่เลือก (ATK/DEF) |

แก้โค้ดแล้วต้อง Deploy > Manage deployments > Edit > New version จึงจะมีผล
